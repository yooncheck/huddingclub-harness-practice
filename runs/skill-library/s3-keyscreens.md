## 레퍼런스 반영 (s1-analysis.md)

- 필터 칩 행 + "총 N개" → 프레임 1
- 바텀시트 필터와 하단 초기화/적용 → 프레임 3
- 프롬프트 박스 우하단 복사 버튼 → 프레임 2
- 번호 단계의 사용 순서 → 프레임 2
- 잠긴 카드는 색이 아니라 문구("유료 멤버 전용이에요…")로 구분 → 프레임 1
- 빈 상태 안내는 이번 키스크린 3장에 넣지 않았다 (S4 화면 디자인에서 상태로 추가)

## 확인한 것

- 모든 프레임 390×844.
- 360px로 줄인 복제본에서 가로로 넘치는 요소 0개 (필터 칩 행은 안쪽 가로 스크롤이 의도라 제외). 처음에는 필터 시트가 390px 고정이라 넘쳤고, 좌우 늘어남 제약을 줘서 고쳤다.
- 좌우 패딩 16 (모든 섹션 컨테이너와 칩 행 시작 위치).
- 제목이 단어 중간에서 줄바꿈되고 상세 화면의 하단 버튼이 프레임 밖으로 잘려서, 제목을 줄이고 간격을 정리해 고쳤다.

## 알려진 차이 (사용자 확인 필요)

- **폰트: Pretendard가 Figma에 없어서 Noto Sans KR로 그렸다.** design.md의 폴백 목록에 있는 폰트다. 굵기 600(SemiBold)은 이 폰트에 없어서 Medium으로 대신했다. Pretendard를 설치하면 폰트만 바꾸면 된다.
- 카드 문구와 프롬프트 본문은 더미 텍스트다 (PRD §14: 더미 텍스트는 직접 조달).
- 난이도 3단계, 카테고리 6개는 PRD에 값이 없어서 임시로 정했다 (s2-spec.md "확인이 필요한 것").
