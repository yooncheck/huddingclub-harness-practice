# pipeline.md

docs/story-work.md의 문장 1~7을 5단계로 묶은 파이프라인.

| 단계 | 포함 문장 | 입력 | 출력 |
|---|---|---|---|
| S1 수집·분석 | 1, 2 | 화면 이름 | 레퍼런스 모음, 분석 내용 |
| S2 설계 | 3 | 분석 내용, PRD | 화면 설계 문서 |
| S3 시안 | 4, 5 | 화면 설계 문서 | 키스크린 2 이상 3 이하, 승인된 컨셉 시안 |
| S4 제작 | 6 | 승인된 시안, design.md | 토큰, 컴포넌트, 화면 디자인 |
| S5 검토 | 7 | 완성된 화면 디자인 | 위반 리포트 (D·C 항목별 통과/실패) |

## 되돌아가는 지점

| 상황 | 돌아가는 곳 |
|---|---|
| S5에서 D 게이트 위반 | S4 |
| S5에서 C 게이트 위반 | S2 |
| S3 승인 반려 | S3 처음부터 |

## 반복 상한

같은 단계로 되돌아간 횟수가 3회를 넘으면(4회째) 멈추고 사람에게 알린다.
