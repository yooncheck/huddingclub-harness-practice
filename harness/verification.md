# verification.md

## 판정 스크립트 검증

- 위반 샘플을 게이트 ID마다 1개씩 만든다 (D1~D13, C1~C8, P1~P5 = 26개).
- 스크립트가 26개 모두 해당 ID로 위반을 내야 한다 (탐지율 100%).
- 통과 샘플 1개는 위반 0건이어야 한다.

## 첫 실행 (dry run)

- 가짜 화면 `sample-screen`으로 S1~S5를 한 번 돌린다.
- 일부러 D3(그림자)와 C2(기본 공개)를 위반시켜서 S5에서 멈추고 S4/S2로 되돌아가는지 확인한다.
- 같은 단계로 되돌림 4회째에 종료 코드 2가 나오는지 확인한다.

## 스크립트가 못 세는 것

Figma 시각 요소는 사용자가 육안으로 확인한다.
- S3 승인 때 스크린샷 1회
- S5 통과 후 최종 시안 1회

## 리뷰

- 스크립트를 쓴 직후 `/code-review` 1회.
- 첫 실제 화면을 돌린 뒤 사용자가 회고한다.
- 규칙을 바꿀 때는 `gates.md`만 수정하고, 바꾼 ID의 위반 샘플을 같이 고치고, 변경 날짜를 gates.md 맨 아래에 적는다.
